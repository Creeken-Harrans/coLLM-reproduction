# 第三轮审查的理论推演（2026-08-15）

## 1. 论文隐含路由率——从表 II FLOPs 锚点反推

论文加速比 = FLOPs_LM / (FLOPs_SM + FLOPs_FNN + p×(FLOPs_LM + FLOPs_R))，
LM=2.21G、SM+FNN≈0.01G、R≈0.03G。反解大模型触发率 p：

| 配置 | FD001 加速 | p(A/B/C) | FD003 加速 | p(A/B/C) |
|---|---|---|---|---|
| CoLLM-A | 3.88× (0.57G) | **25.3%** | 14.54× (0.15G) | **6.4%** |
| CoLLM-B | 2.08× (1.06G) | **47.6%** | 2.29× (0.96G) | **43.2%** |
| CoLLM-C | 1.26× (1.75G) | **78.9%** | 1.57× (1.40G) | **63.2%** |

（我们的定稿在 τ1=0.3/0.4/0.6 下触发 83%/93%/100%（FD001）、0.8%/38%/50%（FD003）——
FD003-B/C 与论文同量级，FD001 严重偏高；α=4/5 是主因，见下。）

## 2. α 与路由率的关系（校准假设）

FNN 良好拟合时 Qs ≈ Q* = 1 − tanh(|es|/α)。半正态 |es|（σ≈MAE·√(π/2)，FD001 σ≈11、
FD003 σ≈9）下 P(Qs<τ) = P(|es| > α·atanh(1−τ))：

| α | FD003 (0.15/0.4/0.6) | FD001 (0.3/0.4/0.6) |
|---|---|---|
| 5   | 49/70/81% | 69/75/85% |
| 10  | 16/44/**64%** | 43/53/70% |
| 15  | 4/25/48% | **24%**/34/56% |
| 论文锚点 | 6.8/**43**/**63**% | **25.6**/**48**/**79**% |

**结论：论文自洽的 α ∈ [10, 15]**（FD003 与 α=10 几乎重合；FD001 介于 10-15 之间，
残余偏差为 FNN 拟合误差所致）。定稿 α=4/5 使 Q* 对典型误差接近饱和 0 → 触发率
系统性偏高 20-100 个百分点——**这是定稿与论文路由行为数量级不符的机制根因**。

## 3. 反思率与 LM/SM 质量差的定量关系

论文 FD003：τ1=0.6 触发 63%，其中反思仅 249/11717=2.1% → 触发样本中仅 3.3%
满足 Δ=Qs−Ql>0.05。若 LM≈SM（论文 11.18 vs 隐含 SM≈11.2），Qs≈Ql → Δ≈0 →
反思罕见 ✓。我们的 LM 12.92 ≫ SM 11.16 → Ql≪Qs → 反思率 50-99% ✗。

**推论：反思率不是独立的可调量，而是 LM/SM 质量差的函数。** 论文的"反思样本
中 >70% 小模型更优"仅在 LM≈SM 时成立（两模型误差联合分布决定）。修复 LM
（→11.2-12.3）后反思率与正确率将机械地回到论文量级——无须对 FNN/R 动手脚。

## 4. LM 差距的候选根因排序（本轮新识别，待实验裁决）

1. **GPT4TS 官方标量头 = GELU → 展平全部 patch → LayerNorm(768·13) → Linear**。
   官方代码（NeurIPS2023-One-Fits-All, Classification/src/models/gpt4ts.py）：
   `outputs = act(outputs).reshape(B,-1); outputs = ln_proj(outputs); outputs = out_layer(outputs)`。
   定稿的 concat 头实验（REVISIONS #29）为裸 Linear(9984→1)——缺失 LayerNorm。
   与 REVISIONS #14（反思网络 9216 维展平 sigmoid 饱和，加 LN 修复）同源：
   9984 维 GPT-2 特征范数大，无 LN 的线性头梯度条件差。**这是本轮最高优先级验证项**。
2. **全量微调**（表 II "Fine-tuning"= 充分微调的解读；III-D 冻结策略只约束 CoLLM 的 LM）。
   此前从未测试。首轮结果：12L 全微调 lr 5e-4 → 14.67（> 定稿 9L 14.31，但首次
   测试已优于 12L 冻结 15.71，方向正确，lr/wd 网格进行中）。
3. **ReplicationPad1d 尾补 → 13 patch**（官方 patching：12 自然 patch + 1 复制尾 patch；
   FLOPs 铁证 2.21G = 12 层 13 patch）。定稿 12 patch 截断丢弃末 2 时间步。
4. **RevIN 输入归一**（官方 forward 内逐样本逐通道 IN；RUL 标量目标不做输出反归一）。
   定稿曾测 IN 无 denorm 得 36.36 而整体放弃——本轮以官方结构重测
   （含 9L/12L×IN 对照，见 experiments/results/）。
