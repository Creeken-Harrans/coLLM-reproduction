## 三阶段训练数据流（用户确认版）
1. **阶段1**：x → SM → y_s（只训 SM+预测头，MSE）
2. **阶段2**：x → patch embed → GPT-2（冻结注意力+FFN）→ y_l（只训 patch embed+预测头）
3. **阶段3**：冻结全部；φs→FNN→Q_s≈1−tanh(|y_s−y*|/α)；φl→FCN→Q_l≈1−tanh(|y_l−y*|/α)

## 推理路由（论文明确，与算法 1 伪代码逐行对照）
```
算法1:
1: φs(x) = SM 特征提取            → 我的实现: small(x) 同时产出 ys 与 φs(x) ✓
2: Qs = F(φs(x); θf)
3-4: if Qs ≥ τ1 → return ys
6: φl(x) = LM 特征
7: Ql = R(φl(x); θr)
8: Δ = Qs − Ql
9-10: if Δ ≤ τ2 → return yl
12: else y_final = G(ys, yl; Δ) = (ys+yl)/2
```
实现文件：`collm/models/collm.py::CoLLM.infer`（含无反思消融分支）。

## 25. FNN 时间聚合方式：stats（mean+max+std+last）——FD001 实测更优（设计决策更新）

- **背景**：算法 1 步骤 2 写 Qs = F(φs(x))，φs(x) ∈ R^{t×d_s} 为完整时间矩阵；
  原实现仅时间均值池化（32 维），丢时序信息。FD001 Qs 校准 Spearman 0.147（弱）。
- **消融**（9 层 LM + m64 FNN，FD001 test）：
  | 聚合 × 特征 | Spearman | CoLLM-A | CoLLM-B |
  |---|---|---|---|
  | mean × fuzzy（原） | 0.147 | 13.499 | 13.64 |
  | stats × fuzzy | 0.204 | **13.251** | **13.068** |
  | stats × raw | 0.261 | 13.447 | 13.160 |
  | stats × raw + α10 | 0.317 | 13.499（触发0%） | 13.327 |
- **结论**：stats × fuzzy 为 FD001 最优（触发 8.1% 时 CoLLM-A 13.25、反思正确率 72%）。
  raw 特征 Spearman 更高但分布偏高导致触发过低。FNN 聚合方式论文未明确，
  属设计自由度（算法 1 的 F(φs) 输入语义支持完整矩阵）。
- **FD003 保持 mean × fuzzy**（stats 使 FD003 变差 10.80→11.74——FD003 触发
  样本 LM 弱于 SM，误触发代价大）。**配置因数据集特性分化，记录在案**。
- **触发率不是越高越好**：论文 LM 12.34 强于 SM 时 25% 触发有益；复现 LM 只在
  最难 ~25% 样本优于 SM，最优触发率 8-21%（与路由价值分析一致，REVISIONS #28）。
