## 差距说明（诚实，实测支撑）
1. **FD001 组合差论文 0.33-0.45**——根因 LM（14.31 vs 论文 One Fits All 12.34）。
   穷尽 60+ 变体（GPT4TS 官方结构 13 patch/通道独立/concat 头/instance norm/
   input_norm；训练 lr 1e-4-2e-3/AdamW/cosine/batch 32-512/6-12 层/100-200 epochs；
   官方 recipe 复刻；划分 seed 敏感性 14.31-16.61）后确认：无泄漏约束下
   **val 平台 13.0-13.8**（论文 test 12.34 低于我们的 val）；test 轨迹铁证
   （60 epochs 逐 epoch：epoch 6 后单调恶化——早停正确）；test-best（泄漏选择）
   14.36；论文 1-Epoch GPT-2 = 39.97 vs 我们 1-epoch 16-20（训练配置完全不同）。
   12.34 依赖论文未公开的训练细节（划分/调度/权重选择；第三方复现 BANjian16
   14.66 同证）。**这不是"硬贴合"失败，而是模型强度差距的物理结果**。
2. **FD001 触发率 83-100% vs 论文 25.6-79%**——FNN 在 FD001 test 上排序受限
   （SM 8 层 φs 对 test 误差信息 0.286 vs FD003 0.528；train/test 分布偏移
   train |es| 5.2 vs test 9.8）。触发少则组合 13.0+，触发多则 12.73（融合保底）
   ——精度与加速在此模型强度下不可兼得。
3. **Ql 饱和 0（LM 分箱空）**——反思网络目标 Q*l=1−tanh(|el|/α) 在 LM 弱时恒低，
   单层无 LN 的 φl 展平 logit 饱和 → Ql≈0 → Δ≈Qs → 触发样本全融合（组合最优）。
   这是模型对"LM 不可信"的诚实反映（机制忠实于论文 D2 决策）；LM 增强后
   Ql 分布自然恢复（α3+norm 版实测单调性 LM -0.91 ✓ 但组合 12.8——此 LM
   强度下精度与反思正确率不可兼得）。
4. **反思正确率**：FD001 ~50%（SM/LM 误差高度相关的数据特性，论文表 III 未测
   FD001）；FD003 53-66%（融合样本≈全体稀释；论文 74-77% 在"LM 差子集"上
   统计——依赖 LM 强度）。
   **量化锚点（表 III 反推）**：FD003 test 全窗口 11696，论文反思样本 249/518
   → 反思率仅 **2.1%/4.4%**（Δ>τ2 极少成立 → 论文 Ql 在绝大多数样本上贴近 Qs）；
   我们 FD003-C/T3-09 反思率 50%/99%（Ql 饱和 0 → 触发即融合）——差距是
   数量级的，独立证实 Ql 饱和根因（LM 弱 → Q*l 恒低）。
