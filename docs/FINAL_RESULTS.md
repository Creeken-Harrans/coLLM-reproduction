## 差距说明（诚实，全部实测支撑）
1. **FD001 组合差论文 0.10-0.18（RMSE）/0.10-0.31（MAE）**——根因 LM 13.92
   vs 论文 One Fits All 12.34。本轮（REVISIONS #50）识别并修复了 LM 输入编码
   偏差（Linear+wpe → One Fits All 官方 Conv1d TokenEmbedding+正弦位置嵌入），
   LM 14.31→13.92，已接近论文 GPT-2 Fine-tuning 13.49；但**距离 One Fits All
   FT 12.34 仍差 1.6**——OFA 官方 recipe 面向 32-token 场景、RUL 标量回归无
   denorm 目标、FD001 小数据（80 unit）LM 过拟合快，12.34 判定为文档化复现边界
   （第三方 BANjian16 14.66 互证）。
2. **FD003 LM 大幅提升（13.28→11.43）**——12 层官方 GPT4TS 结构在 FD003（15907
   窗口、数据足）有效收敛，已接近论文 11.18（差距 0.25）；但组合 A/B 超论文、
   C 高 0.12（SM 10.58 强于 LM 11.43，路由到 LM 有损；反思加 LN 后 C 10.687
   全超论文，REVISIONS #52）。
3. **Ql 在 test 饱和**（FD001 饱和 0 / FD003 饱和 1）——单层 FC（公式 12 字面）
   对 train/test 特征偏移无归一化 → logit 偏移 → sigmoid 饱和。加 LayerNorm 恢复
   校准（FD003 分位 0.21/0.54/0.78、组合 C 11.23→10.69）但 FD001 变差（接受弱 LM
   预测的代价）。**维持无 LN（公式 12 字面，紧贴论文）**；饱和是弱 LM 下机制的
   诚实反映（REVISIONS #52）。论文选择性反思（74-77% 正确）依赖的校准 Ql 在字面
   实现下不可达——属论文未公开自由度。
