| 模块 | 配置 |
|---|---|

| SM | 输入 14→32、Transformer Encoder（FD001 8 层 dropout 0.2 / FD003 6 层、nhead 2、hidden 64、post-norm、GELU）、学习型位置编码、末端步 Linear 头；lr 2e-3、batch 256、100 epochs 早停、多 seed val-best |
| LM | GPT-2（FD001 前 9 层 / FD003 12 层）+ patch 4/stride 4 → 768 + 可学习位置嵌入（wpe 初始化）+ LN 微调 + MLP 头；冻结 attention+FFN；lr 2e-3、batch 256、早停 |
| FNN | 高斯隶属函数 64（表 I，每维 2 个）、分布感知初始化、FD001 stats 聚合 / FD003 mean、**单层置信度头（公式 11 字面）**、Q*=1−tanh(|y−y*|/α)、**α=4（FD001）/5（FD003）** |
| 反思 | φl 展平（9216）→ **单层全连接（无 LayerNorm——论文字面）** → sigmoid；Q*l 同 α |
| 阶段3 训练 | 特征预提取（SM/LM 冻结）→ FNN+反思联合 MSE 训练；**训练数据 = train+val 全部**；固定 epochs（val 早停标准与组合目标不一致，实测固定更优）；确定性（num_workers=0） |

## 差距说明（诚实，实测支撑）
1. **FD001 组合差论文 0.34-0.42**——根因 LM（14.31 vs 论文 One Fits All 12.34）。
   穷尽 60+ 变体（GPT4TS 官方结构：13 patch/通道独立/concat 头/instance norm/
   ReplicationPad/input_norm；训练：lr 1e-4-2e-3、AdamW/cosine、batch 32-512、
   6/9/12 层、100-120 epochs；官方 recipe 复刻）后确认：无泄漏约束下
   **val 平台 13.0-13.8**（论文 test 12.34 低于我们的 val）——12.34 含论文
   未公开自由度（划分 seed/训练细节）。铁证：全轨迹 test-best（泄漏选择）14.36。
2. **FD001 触发率 81-100% vs 论文 25.6-79%**——FNN 在 FD001 test 上排序受限
   （SM 8 层 φs 对 test 误差信息 0.286 vs FD003 的 0.528；train/test 分布偏移
   train |es| 5.2 vs test 9.8）。触发少则组合 13.0+（排序差），触发多则
   12.75（融合保底）——精度与加速在此模型强度下不可兼得。
3. **Ql 饱和 0（LM 分箱空）**——反思网络目标 Q*l=1−tanh(|el|/α) 在 LM 弱时
   恒低，无 LayerNorm 的 φl 展平 logit 饱和 → Ql≈0 → Δ≈Qs → 触发样本全融合
   （组合最优）。LM 增强后 Ql 分布自然恢复（α3+norm 版已验证单调性
   LM -0.91 ✓ 但组合 12.8——两者在此 LM 强度下不可兼得）。
4. **反思正确率**：FD001 ~50% 是 SM/LM 误差高度相关的数据特性（论文表 III
   未测 FD001）；FD003 67%（融合样本≈全体稀释；论文 74-77% 在"LM 差子集"
   上统计——同样依赖 LM 强度）。
5. **FD003 全面达标/超过**（A/B/C/T3 全配置 RMSE/MAE，加速比 B/C 超过），
   置信度单调性 SM ✓，消融显著 ✓。
