## 4. 防泄漏/防过拟合纪律（红线）

1. **test 集只在最终报告出现一次**：所有选择（seed/α/结构/epoch）只依据 val；
   实验脚本打印 test 仅用于对照锚点，不进入任何选择逻辑。
2. 阶段 3 训练数据 = train+val 窗口；test 特征仅评估用。
3. μ/σ 只在 train 划分计算；验证集按 unit 划分（防 49/50 窗口重叠泄漏）。
4. 不训练于 test（论文可能的做法不复刻——即使它是 12.34 的来源）。
5. 多 seed 一律 val-best，禁止"挑 test 好的 seed"。
